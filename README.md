CPTracer pipeline
This repository contains code for extracting and clustering CPTracer barcode sequences, identifying scratchpad mutations, and reconstructing clonal phylogenetic trees. The pipeline is associated with the CPTracer study.

2. Overview
The workflow comprises two stages:
1. FASTQ processing and barcode clustering: execute CPtracer-extraction-1.txt, CPtracer-extraction-2.txt, and CPtracer-extraction-3.txt in that order. These files contain shell commands (despite their .txt extensions).
2. Mutation calling and tree reconstruction: analyze scratchpad alleles, prepare per-clone mutation inputs, and execute the phylogenetic analysis scripts as described below.

3. Barcode extraction and clustering
Input
The extraction workflow was written for single-end 300-bp FASTQ data generated by PCR amplification of CPTracer sequences.

Set the working directory to the folder containing the FASTQ files, and replace your_file_name in each extraction script with the filename prefix (excluding .fastq). For example, sample.fastq uses the prefix sample.
Processing steps
1. CPtracer-extraction-1.txt: trims reads using FASTX-Toolkit, selects reads containing the expected GAGTC motif in the specified interval with SeqKit, and uses Cutadapt to trim the adapter sequence. The script activates a Conda environment called fastx_env; create or adapt this environment before running.
2. CPtracer-extraction-2.txt: filters reads based on their terminal sequence and length, extracts the sequence lines, and prepares the barcode input file for Bartender.
3. CPtracer-extraction-3.txt: clusters barcodes using bartender_single_com and merges barcode cluster and quality files using bartender_combiner_com.
The extraction scripts should be checked for executable shell syntax and local paths before use. In particular, the original scripts embed local environment assumptions, and their output filenames must remain consistent across steps.
Output
The clustering stage produces barcode cluster and quality files and attempts to combine them into a consolidated output using Bartender. The exact combined output name and format should be verified against the installed Bartender version.


4. Allele analysis and phylogenetic reconstruction
Allele input
Following sequence filtering, the first 21 bases correspond to the random DNA barcode; the sequence beginning at position 22 corresponds to the scratchpad. Prepare Alleles.txt with the scratchpad allele sequences, using the sample input files in this repository as formatting examples.
Analysis steps
1. Run Alleleanalysis.phy to identify scratchpad mutations and produce an Excel summary of mutation presence in each allele. Despite the .phy extension, the file contains Python code; run it with Python.
2. Prepare Alldata.txt, input.txt, and any required intermediate files following the provided examples. The original README is ambiguous about the exact number of files to prepare; verify the scripts' input expectations.
3. Run Count.phy to summarize mutation-bearing alleles by clone. Use allele counts to prepare mutation.txt and its FM values.
4. Before running Tree.phy, review the hard-coded total-allele normalization value. The original README cites the following code:
   weights[mut_id] = (fm - 1) / 181695 if total_alleles > 1 else 1.0
   Replace 181695 with the total allele count for your dataset, as instructed in the original README. Confirm the correct count definition against the actual code and input format.
5. Run Tree.phy and Poly.phy in the order specified by the original README. The original README also refers to Conbine.phy, but that file is not present in the currently visible repository file list. Upload the missing script or correct its filename before describing the reconstruction workflow as fully reproducible.
The original README reports these output files:
- allele_visualization.xlsx
- Poly.dnd
- Node_28param_with_depth.txt
- Poly_correct_parent_branches.svg
Output names and successful execution should be validated with the complete set of scripts and example inputs.
